# 판정·모니터링 카드

측정·기록값을 기준과 비교해 묶음(건·배치·기간) 단위로 판정하고, 그룹별 추세와 이상을 찾는 과제.

## 기본 절차
1. **유효한 기록 고르기** — 다시 기록된 건은 어느 것을 쓰나(가장 나중 / 가장 먼저), 오류값·자리 채움 값, 테스트용 기록, 단위가 다른 기록.
2. **묶음 단위 지표** — 판정 단위(건·배치·기간)로 모아 지표를 계산한다. 표본이 너무 적은 묶음은 판정 불가로 따로 둔다.
3. **기준 판정** — 기준 문서의 버전·적용 시작일, 경계값 포함 여부, 판정 등급(정상·주의·불합격 등)과 우선순위(판정 불가 > 특수 상태 > 값 판정).
4. **사유 코드** — 결과를 받는 시스템이 받는 코드 그대로. 판정마다 근거 값(지표와 기준)을 같이 남긴다.
5. **그룹별 추세** — 설비·하위 단위·지역·유형별로 나눠 일별 추세를 본다. 정비·교체·변경 직후 구간은 따로 표시한다.
6. **이상 규칙** — 하루 튐이 아니라 지속되는 변화를 잡는다(아래 계산 메모). 규칙과 그 근거를 문서에 적는다.
7. **시작 시점** — 알림이 뜬 날(알림일)과 변화가 시작된 날(시작일)은 다르다. 알림은 기준을 넘은 뒤에야 뜨므로 시작일이 더 이르다. 둘을 따로 보고하고, 이 기간을 다른 분석에서 뺄 때는 시작일부터 뺀다. 시작일은 추정값이라고 적고 방법을 남긴다.

## 함정 점검 (데이터 신호·담당자 답으로 확인된 것만 체크리스트로)
- [ ] 기준 문서가 최신인가, 기준이 바뀐 날이 있나
- [ ] 경계값과 정확히 같은 값의 처리
- [ ] 같은 대상의 다시 기록·정정 — 어느 것을 쓰나
- [ ] 오류값·자리 채움 값·테스트용 기록
- [ ] 단위가 섞인 행(같은 열에 자릿수가 크게 다른 값)
- [ ] 표본 수가 부족한 묶음
- [ ] 정비·교체·변경 직후 구간
- [ ] 전체 평균에는 안 보이고 하위 그룹에서만 보이는 변화
- [ ] 판정 등급끼리 겹칠 때의 우선순위
- [ ] 알림일을 시작일로 보고하고 있지 않나
- [ ] 값이 조금씩 변하는 이상과 기록 오류값(자리 채움)을 한 가지로 묶어 처리하고 있지 않나

## 계산 메모
- 표본 표준편차 s = √( Σ(x − 평균)² / (n − 1) )
- 흩어짐을 포함한 지표 예: |평균| + k × s (k는 기준 문서·담당자 기준)
- 관리 한계: 기준 기간 평균 ± 3s. 기준 기간을 어디로 잡았는지 적는다.
- 지속성 규칙 예: 같은 쪽으로 n일 연속, 최근 m일 평균이 기준 기간보다 d 이상, 이동 평균의 기울기
- 시작일 추정 ①누적 편차: 기준 기간 평균 μ로 Sₜ = Σ(xᵢ − μ)를 날짜순으로 쌓는다. 변화 전에는 0 근처를 오가다가 시작일부터 한쪽으로 계속 벌어진다 → 꺾이는 날이 시작일.
- 시작일 추정 ②직선 맞추기: 알림일 앞 구간의 일별 값에 직선을 맞춰 기준 기간 평균과 만나는 날을 구한다. ①과 ②가 다르면 둘 다 적고 이른 쪽을 쓴 이유를 남긴다.
- 비율: 주의 이상 비율 = (주의 + 불합격) ÷ 판정한 묶음 수 (판정 불가는 분모에서 뺀다고 적는다)

## 확인 방법
- 원자료에서 한 묶음을 골라 지표를 손으로 계산해 화면 값과 비교
- 경계값·빈 묶음·표본 부족 묶음 테스트
- 그룹별 표(그룹 × 기간)로 이상 알림이 가리키는 곳에 실제로 변화가 있는지
- 각 거르기 단계의 전후 건수
- 시작일을 알림일로 바꿨을 때 뒤따르는 결론(제외 건수, 비교 결과)이 달라지는지
