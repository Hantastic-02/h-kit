# 출처 맞추기·보고서 카드

형식이 다른 여러 출처를 한 기준으로 맞추고, 지표·분해·요약 보고서를 만드는 과제.

## 기본 절차
1. **기준 정하기** — 기간(달력·회계·하루 시작 시각), 통화와 환산 시점, 단위 자릿수, 범위(전체·부분), 버전(최초·정정). 기준은 담당자에게 확인하고 표 맨 위에 적는다.
2. **행 단위 변환** — 원자료 한 행이 어떤 변환을 거쳐 표의 한 칸이 되는지 코드 한 곳에서 처리하고, 변환마다 기록을 남긴다.
3. **겹침 정리** — 같은 대상·같은 기간에 여러 행이 있으면 규칙으로 하나를 고른다(예: 실적 > 추정, 가장 나중 정정). 고른 규칙과 건수를 적는다.
4. **비교 불가 표시** — 범위가 다르거나 자료가 없는 칸은 추정해서 채우지 않고 상태로 표시한다(담당자가 허락하면 예외).
5. **파생 지표** — 비율·점유율·증감률. 분모가 무엇인지(무엇을 더하고 무엇을 빼는지) 적는다.
6. **분해** — 변화를 요인으로 나눈다(아래 계산 메모). 나머지가 생기면 나머지로 따로 보인다.
7. **보고서** — 숫자는 표에서 그대로 가져와 넣고, 문장만 만든다. 숫자마다 출처·기준·추정 여부를 붙인다.

## 함정 점검 (확인된 것만 체크리스트로)
- [ ] 회사·출처마다 기간 정의가 다른가(회계 기간, 마감일)
- [ ] 통화 환산 시점(기간 평균 / 기간 말)
- [ ] 단위 자릿수(천·백만·십억·조 등)
- [ ] 같은 이름인데 범위가 다른 행(전체 vs 일부)
- [ ] 추정치와 실적, 최초와 정정이 같은 칸에 겹침
- [ ] 분모에 같은 것을 두 번 더함(상위 항목에 이미 포함된 하위 항목)
- [ ] 이름이 바뀐 항목(같은 대상, 다른 표기)
- [ ] 반올림을 중간에 해서 합계가 안 맞음
- [ ] 보고서 문장의 숫자가 표와 다름

## 계산 메모
- 증감률 = 이번 ÷ 이전 − 1
- 곱으로 이루어진 값의 변화 분해: 값 = 물량 × 단가이면 (1 + g) = (1 + a)(1 + b) → g = a + b + a·b (a: 물량 효과, b: 단가 효과, a·b: 교차)
- 여러 품목이면 품목별 이전 비중 w로 가중: 전체 g ≈ Σ wᵢ·(aᵢ + bᵢ + aᵢ·bᵢ)
- 점유율 = 대상 값 ÷ 시장 합계(같은 통화·같은 기간)

## 확인 방법
- 원자료 한 행 → 표의 한 칸까지 숫자로 따라가기
- 출처별 합계·건수 대조, 기준을 바꿨을 때 달라지는 칸 수(민감도)
- 보고서 문장의 숫자를 표와 자동으로 대조하는 검사
