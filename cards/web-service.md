# 웹 서비스 기본 카드

과제 README가 기술 스택을 정하면 그쪽을 따른다. 자유라면 아래를 기본으로 한다.
**"항상 필수"**는 뼈대(A 블록)에 넣는다. **"요구할 때만"**은 README나 담당자가 요구한 것만 C 블록에 넣는다.

## 기본 구성
- 서버: Python + FastAPI. 패키지 설치가 막히면 표준 라이브러리(`http.server`, `sqlite3`, `csv`, `json`)만으로.
- 화면: 서버가 주는 HTML + 순수 JavaScript. 그래프는 SVG로 직접 그린다.
- DB: SQLite 파일(경로는 환경변수, 기본값 `runtime/app.sqlite3`). README가 다른 DB를 요구하면 그쪽.
- 폴더 예: `app/`(서버·계산), `app/static/`(화면), `datasets/`(준비한 데이터셋), `tests/`, `evidence/`, `runtime/`(DB, git 제외).

## 흐름 (데이터 처리형 공통)
입력 읽기 → 검증(필수 열, 형식, ID 참조, 값 범위) → 저장 → 정리(사유별 전후 건수 기록) → 계산(입력 데이터 버전을 결과와 함께 저장) → 화면·내보내기.
- 데이터셋을 바꾸는 기능이 있으면: 검증 통과 시 트랜잭션으로 적용하고 버전을 올린다. 실패하면 오류 목록만 보여 주고 기존 데이터를 유지한다. 결과의 버전이 현재 데이터 버전과 다르면 "재계산 필요"를 표시한다.

## 항상 필수
- [ ] 명령 한 줄로 빈 DB에서 시작
- [ ] 켜지면 터미널에 주소, 헬스체크 주소, (계정이 있으면) 계정을 볼 곳, 현재 데이터 버전 출력
- [ ] 0.0.0.0 바인딩, 포트는 환경변수(기본값 있음)
- [ ] 헬스체크가 DB 연결까지 확인
- [ ] 빈 DB에서 테이블·초기 데이터 자동 준비, 껐다 켜도 결과 유지
- [ ] 실행 안내는 터미널 종류별로: bash `export NAME=값`, cmd `set NAME=값`, PowerShell `$env:NAME='값'`
- [ ] 미리보기 창에서 열림: `X-Frame-Options: DENY`, `frame-ancestors 'none'` 쓰지 않기
- [ ] 오류는 그대로 읽히는 문장으로: "파일명 3행: 필수 열 ○○ 없음 — 기존 데이터를 유지했습니다"
- [ ] 정리 기록(거르고 바꾼 건수)이 화면과 내보내기에서 같은 숫자
- [ ] 결과에 어느 입력 데이터·조건으로 만들었는지 함께 저장
- [ ] 원본 데이터 파일 수정 금지
- [ ] SQL은 매개변수로(문자열 이어 붙이기 금지), 화면에 넣는 값은 이스케이프, 경로 입력은 정해진 폴더 안으로만
- [ ] 오류 응답에 내부 경로·쿼리·스택 정보를 내보내지 않기(자세한 내용은 서버 로그로)
- [ ] 규칙과 잘못된 입력 거절을 자동 테스트로

## 화면 기본 (화면이 있으면 항상)
- [ ] 첫 화면 맨 위에 요약: 무엇을 본 결과인지 한 줄 + 핵심 숫자 3~5개(전체 n건, 주의 a건 등) + 데이터 기준일
- [ ] 메뉴는 4~6개, 업무 순서대로. 이름은 하는 일로("판정 결과", "이상 알림")
- [ ] 표의 열 이름은 쉬운 말로. 코드 이름은 괄호나 도움말로
- [ ] 행을 누르면 근거가 보인다: 그 판정에 쓴 값, 기준, 식
- [ ] 결과는 문장으로도: "○○는 기준 3.0을 넘어(3.4) 보류입니다"
- [ ] 빈 상태 안내: "아직 계산한 결과가 없습니다 — ○○를 누르세요"
- [ ] 오류 안내: 무엇이 틀렸는지 + 어떻게 고치는지 + 기존 데이터는 그대로인지

## 요구할 때만
- [ ] 로그인·역할: 권한은 화면뿐 아니라 서버에서도 막는다. 비밀번호는 해시로 저장
- [ ] 초기 계정: 아이디는 고정(역할이 보이는 이름, 문서에 적는다), 비밀번호만 비밀값이다. 비밀번호는 코드에 두지 않는다. 환경변수가 없으면 첫 시작 때 임의로 만들어 해시 저장, 원문은 터미널과 `runtime/initial_accounts.txt`(git 제외)에 한 번 출력
- [ ] 계정 표를 실행 안내와 REVIEW.md에: `역할 | 아이디 | 비밀번호 위치 | 만드는 방식 | 바꾸는 법`
- [ ] 미리보기 창 로그인: 로그인 토큰을 쿠키와 요청 헤더 둘 다 받는다. `SameSite=Strict` 금지. 계정 전환 때 이전 화면 지우기
- [ ] `.env.example`: 모든 환경변수 이름과 설명
- [ ] Dockerfile: 서버와 화면을 함께 실행. 도구가 없으면 빌드는 "미확인"
- [ ] 데이터셋 선택·적용: 서버 폴더에서 목록으로 고르기(업로드·저장창 금지), 트랜잭션 적용, 현재 데이터셋 표시
- [ ] 동시 실행: 적용·계산은 한 번에 하나(잠금), 실행 중 다시 누르면 안내, 오래된 화면의 저장은 버전 검사로 거절
- [ ] 이력: 누가 언제 적용·변경·생성했는지 DB에 남기고 화면에서 보기
- [ ] 내보내기: 화면 표시·복사 또는 서버가 주는 다운로드 링크
