# 선택지 비교·권고 카드

여러 선택지를 같은 가정으로 계산해 비교하고 하나를 권하는 과제. 정해진 규칙을 지키며 자원·일정을 배정하는 과제도 이 카드를 쓴다.

## 기본 절차 (선택지 비교)
1. **선택지 정의** — 무엇을 바꾸는 선택인지, 선택지마다 입력이 어떻게 달라지는지.
2. **같은 가정으로 계산** — 모든 선택지를 같은 입력·같은 코드로 계산한다. 불확실한 입력은 범위(낮음·기준·높음)로 넣는다.
3. **넘으면 안 되는 선** — 이해관계자마다 넘으면 안 되는 값을 묻고, 선택지마다 그 선을 넘는지 표시한다. 평균이 아니라 기간 중 최댓값으로 본다.
4. **입장 정리** — 누가 무엇을 원하고 어디서 부딪치는지 표로. 부딪침을 숨기지 않는다.
5. **민감도** — 가장 불확실한 입력을 바꿔 권고가 바뀌는지.
6. **권고** — 하나를 권하고, 조건(언제 다시 보나, 무엇이 바뀌면 다른 선택지로 가나)을 붙인다.

## 배정·일정 절
1. **규칙과 편의를 나눈다** — 반드시 지킬 것(위반 0건)과 가능하면 좋은 것. 담당자 답으로 알게 된 조건도 규칙에 넣는다.
2. **단순한 방법을 먼저 끝까지** — 우선순위 규칙대로 하나씩 배정하는 방법(욕심쟁이 방법)으로 규칙을 모두 지키는 결과를 먼저 만든다.
3. **개선은 그다음** — 바꿔 넣기·재배치 같은 개선은 같은 입력으로 기준안과 한 표에 놓고 좋아진 것과 나빠진 것을 모두 적는다.
4. **검사기를 따로** — 앱 코드와 따로 만든 규칙 검사기로 결과를 검사한다.

## 함정 점검 (확인된 것만 체크리스트로)
- [ ] 가용 자원이 기간 중에 달라짐(정비·휴무·교체)
- [ ] 단일 추정치만 씀(범위 없음)
- [ ] 제약을 평균으로만 확인함
- [ ] 이해관계자의 선을 모름(물어보지 않음)
- [ ] 같은 입력인데 결과가 달라짐(무작위 시드)
- [ ] 개선이 규칙 위반을 만듦

## 계산 메모
- 선택지 × 지표 표: 각 칸은 같은 가정으로 계산한 값, 선을 넘는 칸은 표시
- 민감도: 입력 하나를 낮음·높음으로 바꿨을 때 권고가 바뀌는 지점(경계값)

## 확인 방법
- 기준안과 각 선택지를 같은 입력으로 다시 계산해 표가 재현되는지
- 규칙 검사기 위반 0건
- 민감도 표에서 권고가 바뀌는 경계를 문서에 적었는지
