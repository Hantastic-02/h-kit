# 두 그룹 비교·판단 카드

전·후, A·B, 기존·신규처럼 두 그룹을 비교해 "차이가 있나, 바꿔도 되나"를 판단하는 과제.

## 기본 절차
1. **비교 단위 정하기** — 개별 측정이 아니라 판단 단위(건·배치·사람·기간)의 평균으로 비교하는지 정한다.
2. **공정한 비교** — 결과에 영향을 주는 다른 조건(설비·기간·대상·경로)이 두 그룹에 고르게 섞였는지 본다. 고르지 않으면 같은 조건끼리 나눠 비교하고(층별 비교) 층별 차이를 합친다.
   - **작은 층** — 한쪽 건수가 최소 표본 수(담당자에게 묻고, 답이 없으면 가정으로 정한다)보다 적은 층은 합칠 때 빼고 "표본 부족"으로 따로 표시한다. 한쪽이 한두 건뿐인 층이 결론을 정하게 두지 않는다.
   - **상위 판단은 가중 합으로** — 층보다 위 수준의 결론은 층별 차이를 건수로 가중해 합친 값으로 낸다. "한 층이라도 기준을 넘으면" 규칙은 담당자가 그렇게 말했을 때만 쓴다(원문을 PLAN 5절에).
3. **제외할 것** — 테스트용·샘플·이상 기간(다른 원인이 확인된 기간)을 빼고 건수를 적는다. 이상 기간은 알림이 뜬 날이 아니라 **변화가 시작된 날부터** 뺀다(시작일 추정은 judge-monitor 카드 7단계).
4. **차이 보기** — 평균 차이, 흩어짐 비율, 꼬리(가끔 크게 튀는 값의 빈도), 기준 밖 비율 차이.
5. **기준을 숫자로** — "크게 다르지 않으면" 같은 말은 담당자에게 숫자를 받는다. 못 받으면 가정으로 정하고 민감도를 본다.
6. **결론 단계** — 예: 승인 / 조건부(어떤 범위에서만, 어떤 감시를 붙여서) / 보류. 조건과 다시 볼 시점을 붙인다.

## 함정 점검 (확인된 것만 체크리스트로)
- [ ] 한 그룹이 특정 조건(설비·기간·대상)에 몰려 있나
- [ ] 같은 시기에 다른 변화(정비·설정 변경·이상)가 있었나
- [ ] 테스트용·샘플이 섞였나
- [ ] 표본 수가 너무 적은 층 — 그 층 하나가 상위 결론을 정하고 있지 않나
- [ ] 층별 결과를 합치는 규칙(하나라도 / 가중 합)을 담당자에게 확인했나
- [ ] 이상 기간 제외가 알림일이 아니라 시작일부터인가
- [ ] 평균만 보고 흩어짐·꼬리를 놓침
- [ ] 단위·척도가 섞인 값
- [ ] 여러 하위 항목을 동시에 비교해서 우연히 하나가 걸리는 경우

## 계산 메모
- 층별 차이 dₖ = 평균(B, 층 k) − 평균(A, 층 k). 합친 차이 = Σ wₖ·dₖ / Σ wₖ (wₖ: 층 k의 두 그룹 중 작은 쪽 건수 등, 정한 방식을 적는다)
- 효과 크기 = 차이 ÷ 기준 그룹 표준편차
- 비율 차이 = (B의 기준 밖 수 ÷ B 건수) − (A의 기준 밖 수 ÷ A 건수)
- 참고용 검정(Welch t): t = (평균B − 평균A) / √(sA²/nA + sB²/nB). 결론은 담당자 기준 숫자로 내고 검정은 보조로만 쓴다.

## 확인 방법
- 층별 비교와 단순 비교(나누지 않고 전체 비교)를 한 표에 놓고 결론이 같은지
- 제외 전후 결론이 바뀌는지
- 기준 숫자를 조금 바꿔도 결론이 유지되는지(민감도)
- 합치는 규칙, 최소 표본 수, 이상 기간 시작일을 바꿨을 때 결론 표: `선택 | 값 | 결론`
