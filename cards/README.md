# 방법 카드 고르기

과제의 **모양**으로 고른다. 주제(분야) 이름으로 고르지 않는다. 한 과제에 1~2장이면 충분하다. 웹 화면이 있으면 `web-service.md`를 함께 읽는다.

| 과제 모양 | 카드 |
|---|---|
| 측정·기록값을 기준과 비교해 판정하고, 추세와 이상을 본다 | `judge-monitor.md` |
| 두 그룹(전·후, A·B, 기존·신규)을 비교해 차이가 있는지 판단한다 | `compare-groups.md` |
| 형식이 다른 여러 출처를 한 기준으로 맞추고, 지표와 보고서를 만든다 | `reconcile-report.md` |
| 여러 선택지를 같은 가정으로 계산해 비교하고 하나를 권한다 | `scenario-decide.md` |
| 지표가 나빠진 원인을 데이터로 좁히고 분석 보고서를 낸다 | `find-cause.md` |
| 정해진 규칙을 지키며 자원·일정을 배정한다 | `scenario-decide.md`의 "배정·일정" 절 |

카드는 절차와 점검 목록이다. 카드에 적힌 함정이 이번 데이터에 실제로 있는지는 kit-start의 데이터 신호와 담당자 답으로 확인한 뒤에만 체크리스트에 넣는다.
