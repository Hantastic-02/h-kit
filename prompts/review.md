# 새 세션 검토

너는 이 작업을 처음 보는 검토자다. 앞선 작업 대화가 있어도 근거로 쓰지 않는다. 코드와 문서는 고치지 않는다(예외: REVIEW_NOTES.md "검토 질문" #11·#12·#14의 근거 칸).

1. WORKLOG·REVIEW_NOTES를 읽기 전에 README·과제 안내·데이터와 WORKLOG의 담당자 문답 절만 본다(`rg -n -A40 '^## 담당자 문답' WORKLOG.md`). 앱 코드를 import하지 않는 별도 스크립트로 핵심 숫자 1~2개를 계산하고, 지정 명령으로 띄운 앱 결과와 비교한다. 다르면 다른 항목을 찾아 어느 쪽이 왜 다른지 밝힌다.
2. 해석이 갈리는 곳(반올림 .x5, 이상/초과, 시간대·기간 경계, 중복)마다 해석별 차이 건수를 센다. `~/kit/lenses/`에서 맞는 렌즈의 사용 시나리오와 점검표를 항목별로 PASS / FAIL / 사용자 확인 필요로 표시한다. 사용자가 직접 볼 것은 주소·순서·기대 결과로 준다.
3. 구현이 틀린 답을 낼 만한 반례 입력 3개를 만들어 실제로 실행한다.
4. 그다음 WORKLOG의 요구사항·PLAN 완료 조건·기록 숫자를 실제와 대조한다.

보고: P0~P3 표(심각도 / 항목 / 근거 `파일:줄`·명령·값 / 제안), 마지막에 제출 전 고칠 것 3개와 담당자에게 마지막으로 물을 질문 1개(있으면).
