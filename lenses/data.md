# 렌즈: 데이터 처리 (판정·집계·파이프라인)

## 함정 관점 (데이터로 센다)
- 분모와 대상: 테스트·더미·중단·제외 대상, 분모가 바뀌면 결과가 몇 % 바뀌나
- 기간 경계: 하루의 시작(00시 / 06시 공장 일자 / 교대), 시간대(UTC·KST), 기준 시각 이후 기록
- 중복: 재전송·재시도·수집기 중복 줄, 최종 차수만 유효한지
- 표기 흔들림: 대소문자·공백·단위(Å/nm, 화씨/섭씨)·음수
- 기준값과 정확히 같은 값(이상/초과), 표시 반올림 경계(.x5)
- 순서: 파일 순서 ≠ 발생 순서, 늦게 붙은 행

## 사용 질문 (2개 고른다)
- 결과를 받으면 다음에 누가 무엇을 하나요? 보류·예외 건은 따로 목록이 필요한가요?
- 지금은 사람이 어떻게 처리하고, 가장 자주 틀리는 부분은 어디인가요?
- 결과를 어떤 형식·시스템으로 넘기나요?

## 기대값 출처
- 문서·담당자 예시, 사용자가 손으로 계산한 3건(정상·경계·예외)

## 사용 시나리오 (review)
- 결과 파일을 받은 사람이 열어서 다음 행동(재측정·보류·보고)을 바로 할 수 있나
- 같은 형식의 다른 데이터로 지정 명령을 다시 돌려도 같은 기준으로 나오나

## 서술형 단골
- 단계별로 거른·바꾼 건수
- 다른 기준(0시 vs 06시 등)과 숫자가 왜 다른가, 어느 쪽이 맞는지 확인 방법
- 기준값이 바뀌면 고칠 곳과 늘어나는/줄어드는 건수
