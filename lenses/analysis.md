# 렌즈: 원인 분석·보고

## 함정 관점
- 같이 움직이는 변수(교란): 원인 후보와 같은 시기에 바뀐 다른 것
- 시간 순서: 원인 후보가 결과보다 먼저 일어났나
- 측정 오류: 센서 고장·단위(화씨)·장비별 차이, 재테스트·중복 측정
- 제외 대상: 엔지니어링·테스트 로트, 대조군(골든 웨이퍼 등)
- 쏠림: 특정 장비·레시피·작업자·기간에 몰리는지

## 사용 질문 (2개 고른다)
- 보고를 누가 받아 무엇을 결정하나요? 확정과 추정을 어떻게 구분해 주길 원하나요?
- 최근에 바뀐 장비·레시피·자재·작업자가 있나요? 현장에서 의심하는 원인은?

## 기대값 출처
- 원인 후보마다 근거(지지)와 반증(반대 근거)을 숫자로, 대조군과 비교

## 사용 시나리오 (새 세션 검토)
- 보고를 처음 받는 사람이 결론·근거·확신 정도·다음 조치를 1분 안에 읽을 수 있나

## 서술형 단골
- 다른 원인일 가능성을 어떻게 배제했나
- 추가로 데이터가 있다면 무엇을 보겠나
- 결론이 틀렸다면 어떤 손해가 생기나
